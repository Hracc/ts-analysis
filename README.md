# Итоговый отчет: Анализ и прогнозирование дорожного трафика

!!! Данный репозиторий создан для сдачи итоговое дз по АВР!!!  

## 1. Описание задачи и набора данных

### 1.1. Постановка задачи
Целью данной работы является построение и сравнение моделей машинного и глубокого обучения для прогнозирования интенсивности дорожного трафика. Необходимо подготовить данные, провести разведочный анализ (EDA), обучить не менее 3 методов ML и 3 методов DL, оценить их качество и выбрать лучшую модель для финального пайплайна.

### 1.2. Описание набора данных
Используется датасет `traffic.csv` из примера преподавателя, содержащий данные об интенсивности дорожного движения.
**Основные характеристики:**
- **DateTime**: Временная метка (дата и время).
- **Junction**: Идентификатор перекрестка (`unique_id`).
- **Vehicles**: Целевая переменная – количество транспортных средств (`y`).

Данные были приведены к стандарту библиотек для прогнозирования (NeuralForecast / Prophet):
- `Junction` переименован в `unique_id`.
- `DateTime` преобразован в тип `datetime` и переименован в `ds`.
- `Vehicles` переименован в `y`.
- Пропущенные значения отсутствуют (0 пропусков по всем колонкам).

## 3. Моделирование и оценка качества

### 3.1. Выбранные модели
Для решения задачи были выбраны и обучены следующие алгоритмы:
1. **Методы машинного обучения (ML / Stat):**
   - `AutoARIMA` (Автоматизированная авторегрессионная интегрированная модель скользящего среднего)
   - `AutoTheta` (Автоматизированная модель Theta)
   - `XGBRegressor` (Градиентный бустинг на деревьях)
   - `LGBMRegressor` (LightGBM)
   - `CatBoostRegressor` (CatBoost)
2. **Методы глубокого обучения (DL):**
   - `NBEATS` (Neural Basis Expansion Analysis for Time Series)
   - `LSTM` (Long Short-Term Memory)

### 3.2. Метрики оценки
- **MAE (Mean Absolute Error)**: Средняя абсолютная ошибка. Показывает среднее отклонение прогноза от факта в реальных единицах (автомобилях). Легко интерпретируется.
- **RMSE (Root Mean Squared Error)**: Корень из среднеквадратичной ошибки. Более чувствительна к крупным выбросам и сильнее штрафует модель за критические промахи в пиковые часы.

## 4. Итоговый пайплайн и выводы

### 4.1. Выбор финальной модели
На основе метрик (наименьшие MAE и RMSE) лучшим результатом обладали градиентные бустинги (**XGBoost**) и статистическая модель **AutoTheta**. Однако, для задач временных рядов с выраженными паттернами, **NBEATS** и **LSTM** также показали высокую стабильность и обобщающую способность, что делает их отличными кандидатами для продакшн-пайплайна, особенно при наличии больших объемов исторических данных.

В финальном пайплайне для демонстрации была выбрана архитектура **LSTM** (через библиотеку `NeuralForecast`), так как она хорошо масштабируется и эффективно улавливает нелинейные зависимости во временных рядах.

### 4.2. Реализация пайплайна
Финальный пайплайн включает:
1. Загрузку и предобработку данных (приведение к формату `ds`, `y`, `unique_id`).
2. Инициализацию модели `NeuralForecast` с архитектурой `LSTM` (параметры: `input_size=48`, `h=24`, `max_steps=100`, `encoder_hidden_size=64`).
3. Кросс-валидацию (`cross_validation`) с горизонтом 24 шага и 3 окнами для оценки стабильности.
4. Экспорт прогнозов в стандартизированный файл `final_pipeline_predictions.csv`.

### 4.3. Итоговые выводы
Данные чистые, ряды стационарны, что упрощает задачу прогнозирования.

Ансамбли на основе градиентного бустинга (XGBoost) показали себя лучше всего по метрикам ошибки на данном конкретном наборе данных, опередив даже сложные архитектуры глубокого обучения (LSTM, NBEATS) и классическую AutoARIMA.

Время обучения и генерации прогнозов финальной модели находится в приемлемых пределах для практического применения.
