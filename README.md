## 0. Предисловие
В этом файле собраны ключевые выводы и численные результаты работы. Полный программный код, детальные графики, анализ остатков и визуализация доверительных интервалов находятся в ноутбуке `final_homework.ipynb`. Рекомендуется открывать его параллельно, если потребуются технические детали.

## 1. Задача №1. Подготовка данных и разведочный анализ

Работа ставит задачей прогнозирование интенсивности трафика на сутки вперед (горизонт 24 часа). Обучение проходит в офлайн-режиме с использованием глобальных моделей, которые обучаются на всех перекрестках одновременно, чтобы уловить общие городские паттерны движения.

В качестве основы взят датасет `traffic.csv`, содержащий 48 120 часовых наблюдений с четырех перекрестков. Данные приведены к стандарту экосистемы Nixtla (`unique_id`, `ds`, `y`), пропуски отсутствуют, типы временных меток корректны. 

Разведочный анализ показал четкую внутрисуточную сезонность с выраженными утренними и вечерними «часами пик», а также устойчивые недельные колебания. Проверка стационарности расширенным тестом Дики-Фуллера вернула нулевой p-value для всех рядов. Это позволяет считать их статистически стационарными и применять классические модели без дополнительного взятия интегральных разностей. Отдельно отмечено, что история по четвертому перекрестку примерно втрое короче остальных, что учтено при настройке глобальных алгоритмов.

> **Вывод по Задаче №1:** Данные чистые, корректно размечены и подготовлены к. Ряды стационарны, обладают сильной суточной сезонностью. Метрики оценки (MAE, RMSE) и горизонт прогноза зафиксированы.

## 2. Задачи №2 и №3. Сравнение статистических, ML и DL методов

Для объективной оценки было протестировано несколько подходов: от простых бейзлайнов до современных нейросетевых архитектур. Ниже приведена таблица с обоснованием выбора каждого метода.

| Тип метода | Модели | Почему выбраны |
| :--- | :--- | :--- |
| **Бейзлайн** | `Naive`, `SeasonalNaive` | Задают нижнюю границу качества. Сезонная наивная модель отлично ловит базовые суточные повторения. |
| **Статистика** | `AutoARIMA`, `AutoETS`, `AutoTheta` | Классические подходы. ARIMA устойчив к шуму, ETS хорошо сглаживает тренды, а Theta традиционно сильна на рядах с ярко выраженной сезонностью. |
| **ML (Бустинги)** | `XGBRegressor`, `LGBMRegressor`, `CatBoost` | Эффективно работают с табличными данными. За счет ручного извлечения календарных признаков (час, день недели) быстро адаптируются к расписанию трафика. |
| **DL (Нейросети)** | `NBEATS`, `NHITS`, `LSTM` | Архитектуры, созданные специально для временных рядов. LSTM ловит нелинейные долгосрочные зависимости, а NBEATS/NHITS автоматически декомпозируют ряд на тренд и сезонность. |

Качество оценивалось через кросс-валидацию на трех скользящих окнах. Для статистических моделей дополнительно рассчитывались 80% и 95% доверительные интервалы, что позволило оценить не только точность точечного прогноза, но и надежность вероятностных оценок. Фактические значения стабильно укладывались в 95%-й коридор, а анализ остатков подтвердил отсутствие систематической ошибки (среднее ≈ 0).

| Модель | Тип | MAE | RMSE |
| :--- | :--- | :--- | :--- |
| **XGBRegressor** | ML | **3.285** | **4.362** |
| **AutoTheta** | Stat | 3.366 | 4.548 |
| **LGBMRegressor** | ML | 3.438 | 4.518 |
| **CatBoostRegressor**| ML | 3.487 | 4.664 |
| **NBEATS** | DL | 3.568 | 4.637 |
| **NHITS** | DL | 3.726 | 4.797 |
| **LSTM** | DL | 3.769 | 4.827 |
| SeasonalNaive | Base | 4.194 | 5.883 |
| AutoARIMA | Stat | 4.252 | 5.681 |
| AutoETS | Stat | 8.934 | 15.109 |
| Naive | Base | 10.829 | 15.930 |

> **Вывод по Задачам №2 и №3:** На данном датасете градиентные бустинги и модель AutoTheta показали лучшие численные результаты, обойдя даже нейросетевые архитектуры. AutoETS оказался неэффективен из-за излишнего сглаживания, тогда как методы глубокого обучения (LSTM, NHITS) отличились высокой стабильностью и хорошей обобщающей способностью.

## 3. Задача №4. Финальный пайплайн и тестирование

Ядром итогового решения выбрана архитектура LSTM, реализованная через фреймворк `NeuralForecast`. Модель принимает на вход окно из 48 часов и прогнозирует следующие 24, используя скрытый слой размера 64. Обучение на GPU занимает около 2.2 секунды, а полный инференс вместе с бэктестингом укладывается в 7.6 секунды, что делает решение пригодным для интеграции в реальные системы. 

На этапе финального тестирования пайплайн достиг MAE 3.03 и RMSE 4.18. Результаты автоматически сохраняются в стандартизированный файл `final_pipeline_predictions.csv`, готовый к передаче во внешние сервисы.

> **Вывод по Задаче №4:** Сквозной DL-пайплайн успешно собран, протестирован на производительность и стабильность. Финальная модель LSTM превзошла базовые статистические алгоритмы и классические бустинги по итоговому качеству на кросс-валидации, сохранив при этом высокую скорость работы.

## 4. Общее заключение о проделанной работе

В ходе выполнения итогового задания был исследован датасет интенсивности дорожного трафика (`traffic.csv`, 48 120 наблюдений, 4 перекрестка) и построен end-to-end пайплайн прогнозирования на горизонт 24 часа. 

Разведочный анализ подтвердил стационарность рядов (тест Дики-Фуллера, p-value = 0.0000) и выявил сильную суточную сезонность. Было проведено масштабное сравнение алгоритмов: два бейзлайна, пять статистических моделей (с расчетом доверительных интервалов), три метода машинного обучения с ручным Feature Engineering и три архитектуры глубокого обучения. 

На этапе изолированного сравнения лучшие показатели продемонстрировали XGBoost (MAE=3.28) и AutoTheta (MAE=3.37). Однако собранный финальный пайплайн на базе LSTM показал наилучшее качество (MAE = 3.03, RMSE = 4.18), успешно улавливая нелинейные паттерны и пиковые нагрузки при скорости инференса ~7.6 сек. Работа охватывает полный цикл исследования: от предобработки и проверки стационарности до развертывания готового DL-пайплайна с автоматическим экспортом прогнозов.
